# Cake website — starter

This is a deliberately small, mobile-first starter for a custom-cake business.

## Files

- `index.html` — page content, business copy, order form, and appearance-editor shell. Edit all visible business copy here.
- `styles.css` — visual tokens and starter layout.
- `script.js` — draggable, expandable settings bauble behaviour.
- Long-press any heading, paragraph, or ordinary link on the page to edit its copy. The compact toolbar offers alignment, font size, bold, and Done controls; edits persist on that device.
- `assets/images/cakes/` — supplied photos, renamed `cake-01.jpg` through `cake-05.jpg`.
- `assets/images/backgrounds/red-velvet-crumb-2048.png` — 2048×2048 generated cake crumb base; frosting bands and subtle pores are layered by CSS/JavaScript so they remain independently adjustable.
- `custom.html`, `flavors.html`, `gallery.html`, `about.html`, and `order.html` — one-screen linked destination pages.

## Remaining phases

1. Replace the sample business name, location, contact email, copy, and ordering details directly in `index.html`.
2. Tune the generated cake texture, frosting-band positions, and featured image treatment after viewing on the target phone.
3. Refine the three appearance branches already started here: Color (background, main text, title, description), Type (size, body size, weight, spacing), and Photos (frame, crop, softness, image selection).
4. Persist chosen settings so they survive a page refresh, then add a reset-to-default action.
5. Add editable site sections and the custom-cake ordering flow.
6. Test the radial baubles on small and large phone screens, including arc spillover at every edge and corner.
7. Replace placeholders, do final mobile QA, and publish.
